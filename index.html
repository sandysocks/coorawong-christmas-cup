Automatically track my runs?

Set up an iPhone Shortcut once, and your runs from Apple Health get logged here every evening. Takes about 5 minutes.

I am:

1. Create the automation

  1. Open the Shortcuts app and tap Automation, then + (or "New Automation").
  2. Choose Time of Day, set it to 9:00 pm, Daily, and pick Run Immediately. Tap Next, then New Blank Automation.

2. Find today's runs

  1. Add Find Health Samples. Set Type to Workouts, add filters Workout Type is Running and Start Date is today.
  2. Add If: if Health Samples has any value. Put the next steps inside the If.
  3. Add Get Details of Health Sample → Distance. Then Calculate Statistics → Sum. If it's in metres, add Calculate ÷ 1000. Rename the result Km.
  4. Add Get Details of Health Sample → Duration on the original samples, then Calculate Statistics → Sum. Make sure it's in minutes (÷ 60 if it's seconds). Rename it Minutes.
  5. Add Format Date on Current Date, Custom format yyyy-MM-dd. Rename it RunDate.

3. Send it to the Cup

  1. Add Get Contents of URL with this URL:
  2. Tap the arrow: Method POST, Request Body Form, and add four text fields:
    →
    → RunDate
    → Km
    → Minutes
  3. Optional: add Show Notification "Logged Km km to the Cup 🏃". Tap Done.

Test it

Go for a run, open the automation and tap ▶ to run it by hand, then check the ladder (it can take ~5 minutes to show up). If your iOS doesn't offer Workouts as a type, use the Log a run button instead, and tell Sandy.

Forgot your watch? The Log a run button always works. Running the shortcut twice in a day will log the run twice, so just once a day.
